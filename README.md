# HR Governance Audit

A Next.js app for auditing an organization's HR policy governance documentation: track a 25-document checklist, compute an Audit Score (documents available) and a weighted Compliance Score with maturity band, and generate an AI-style summary report. Access is role-based (Admin, HR Manager, HR Employee, IT), with editing restricted to Admin and HR Manager.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
